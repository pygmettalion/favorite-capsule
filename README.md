# 최애 자판기

취향을 고르고 캡슐을 다섯 번 두드리면 결과가 나오는 동아리 시연용 웹페이지입니다.

- 얼굴형·눈·코·입 선택, 선택 사항인 MBTI
- 체험 뽑기권, 캡슐 열기, 뽑기 영수증
- 결과 평가 후 세 장 중 고르는 연애운 카드
- 모바일 터치와 키보드 조작 지원

이미지와 글꼴이 `index.html`에 포함되어 있어 별도 서버, 설치, API 키가 필요하지 않습니다. 선택 내역은 방문자의 브라우저에만 저장됩니다. 실제 결제 기능은 없습니다.

## 배포

GitHub 공개 저장소에서 Settings → Pages → Deploy from a branch → main / (root)를 선택합니다. GitHub Pages 기본 주소를 사용하며 유료 서버, 유료 도메인, 유료 API를 사용하지 않습니다.

## 데모 조합

| 결과 | 얼굴형 | 눈 | 코 | 입 |
| --- | --- | --- | --- | --- |
| 도훈 | 땅콩형 | 범눈 | 직선코 | 하트 |
| 남주혁 | 계란형 | 사자눈 | 직선코 | 하트 |

이미지는 시연을 위해 제공받은 자료입니다. 글꼴의 라이선스 안내는 페이지에 포함되어 있습니다.
